# Documentation guidance

- Keep `README.md` task-oriented, `code-walkthrough/README.md` implementation-oriented,
  and `project-goals/README.md` focused on target requirements and alignment status.
- Do not describe a schema, protocol, dependency, or interface as implemented unless a
  runnable adapter/path exists. Mark scaffolding honestly as partial or planned.
- Update commands, environment variables, URLs, file paths, and limitations alongside
  code changes. Examples must be safe for the local stack and must not imply that local
  credentials or permissive Keycloak settings are production-safe.
